# STREET RUSH: TRIPURA — Web Prototype

A browser-playable arcade street racing prototype inspired by Indian street racing, set in Agartala, Tripura. The main-menu skyline features a stylized Udaipur-lake sunset.

## Play it on GitHub Pages
1. Open the repository Settings → Pages.
2. Under Build and deployment, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then Save.
4. Wait for the Pages deployment, then open the published URL shown in Settings → Pages.

The game is in `index.html` and uses Canvas, so it has no build step or external libraries.

## Controls
- **W / Up Arrow:** accelerate
- **S / Down Arrow:** brake/reverse
- **A/D / Left/Right:** steer
- **Space:** drift
- **Shift:** nitro
- **Esc:** return to menu
- Mobile touch controls are included.

## Current scope
This is an early 2D pseudo-3D browser prototype with a neon menu, stylized sunset/lakeside scenery, arcade steering, speed and nitro HUD, and three checkpoints. It is not a finished 3D NFS-scale game; 50+ detailed vehicle models, traffic AI, licensed car assets, and a true 3D world remain future work.
